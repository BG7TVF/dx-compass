# M2 / MM 团队协作模式与操作流程（可直接转 SOP）

> 配套文档：[M2/MM 规则硬约束](file:///d:/岑溪基地/Node-Red-Contesting-Dashboard/docs/m2-mm-rules-constraints.md)
>
> 标记约定：
> - **[规则]** 有官方规则原文支持，违反会判违规/降组；
> - **[实践]** 队伍做法，规则未要求，按队伍条件取舍；
> - **[待验证]** 需要本队实测校准，不能当默认真理。
>
> 本文的“M2”默认指 CQ WW / WPX 型 M2；“ARRL M2”单独标注，因为换波段配额是 6 次而非 8 次。

---

## 0. 先定三件事（赛前必须写进台务卡）

1. **组别与规则族**：CQ WW M2 / WPX MULTI-TWO / ARRL DX M2 / CQ WW MM / WPX MULTI-UNLIMITED / ARRL DX MM。不同规则族的换波段配额、序号、乘数台限制不同。
2. **比赛波段**：CQ WW / WPX / ARRL DX 都只有 **160/80/40/20/15/10** 六个波段；不要按 WARC 波段排班。
3. **发射信号上限**：M2 = 2 个，且必须不同波段；MM = 每波段 1 个，最多 6 个。**任何时刻同波段只能一个信号**（三家通用）。

> **[规则 + 解释] 非发射席位不占信号数。** 规则限制的是“transmitted signals”，不发射的辅助/传播/日志/指挥席本身不构成信号；但只要在比赛模式发射，就计入信号数。不要把“辅助席”当成可以随意 CQ 的第三信号。

## 1. 席位怎么分

### 1.1 M2 席位（2 个发射信号 + 若干非发射席）

| 席位 | 是否发射 | 主要职责 | 关键产出 | 备注 |
|---|---|---|---|---|
| **A 席：主跑台（Anchor RUN）** | 是 | 守高率波段，建立 pileup，连续 CQ | 稳定 QSO 率、主频率 | 尽量少换波段，把 8 次配额留给传播切换 |
| **B 席：猎台/第二跑台（Hunter）** | 是 | 抓乘数、补缺口；必要时也 CQ | 新 DXCC/zone、缺口清单 | **[实践]** 多数队伍让 B 多做 S&P；**[规则]** M2 并未禁止 B CQ |
| **C 席：日志与乘数管理（Logger/Mult Manager）** | 否 | 盯乘数板、核对日志、记录交接、维护频率占用表 | 乘数缺口 Top N、日志异常、交接记录 | 不发射，不占信号数 |
| **D 席：传播与情报（Prop/Assist）** | 否 | 盯灰线、MUF、spot 流、对手位置 | 波段开闭窗口、可通性变化 | 与 C 席可合并 |
| **E 席：指挥/队长（Captain）** | 否 | 决定换波段、开人、停人；处理冲突 | 决策与复盘 | 小队伍可由 A 席兼 |

**M2 的硬分工原则 [规则 + 实践]：**

- **[规则]** A、B 必须始终在两个不同波段；不能同时占 20m。
- **[规则]** A、B 各自有独立的 8 次/小时配额（ARRL 为 6 次），**不能互借**；C 席必须分台记账。
- **[实践]** A 席“低动”、B 席“按预算动”：A 席的配额主要留给传播窗口切换；B 席的配额用于抓乘数。
- **[实践]** C 席是 M2 的“共享内存”：所有“谁在哪个波段/频率、还剩几次配额、缺什么乘数”都汇总到 C 席，而不是让 A/B 互相喊。

### 1.2 MM 席位（每波段 1 个信号）

| 席位 | 是否发射 | 主要职责 | 关键产出 |
|---|---|---|---|
| **160m 席** | 是 | 守 160m，抓夜间/灰线乘数 | 160m QSO + 乘数 |
| **80m 席** | 是 | 守 80m | 80m QSO + 乘数 |
| **40m 席** | 是 | 守 40m，昼夜过渡 | 40m QSO + 乘数 |
| **20m 席** | 是 | 守 20m，白天主率 | 20m QSO + 乘数 |
| **15m 席** | 是 | 守 15m，白天高率 | 15m QSO + 乘数 |
| **10m 席** | 是 | 守 10m，白天/Es | 10m QSO + 乘数 |
| **乘数指挥（Mult Captain）** | 否 | 跨波段缺口分配、认领/完成状态 | 全局乘数板、任务分派 |
| **日志/指挥（Log/Command）** | 否 | 日志一致性、换人记录、冲突裁决 | 统一日志、操作员轮换表 |
| **传播/情报** | 否 | 灰线、MUF、spot 流、对手 | 波段开闭与可通性 |

**MM 的硬分工原则 [规则 + 实践]：**

- **[规则]** 每个波段最多 1 个信号；六个波段可同时工作；无 band change 限制。
- **[规则]** 所有席位共用同一个参赛呼号；不能每个波段一个呼号。
- **[实践]** MM 的决策单位不是“换波段”，而是“**这个波段现在值不值得占一个人**”：看该波段 eQSO/hr、乘数边际、传播剩余时间。
- **[实践]** 乘数指挥不直接发射；它把“哪个波段需要谁去抓”变成任务，交给对应波段席或空闲席。

### 1.3 MS 的对照（避免把 M2 习惯套到 MS）

| 项目 | CQ WW MS | WPX MULTI-ONE / ARRL DX MS |
|---|---|---|
| 信号数 | 2（run + multiplier） | 1 |
| 乘数台 | 有；不得 CQ；只能新乘数；必须不同波段；独立 10 分钟锁 | 无 |
| 换波段约束 | 10 分钟锁 | 10 次/小时 |
| 席位 | RUN + MULT + 辅助 | RUN + 辅助（辅助不发射） |

> **[规则] 不要把 CQ WW MS 的“乘数台不得 CQ”写进 M2 的台务卡。** M2 没有这个规则身份；如果队伍想限制 B 席 CQ，那是战术选择，要标 [实践]。

## 2. 频段怎么分配与交接

### 2.1 M2 的频段分配（[实践] 模板，按传播调整）

| 时段/传播 | A 席（主跑） | B 席（猎/副跑） | 说明 |
|---|---|---|---|
| 白天（当地 08–16） | 20m 或 15m | 10m / 15m 缺口 | A 守高率；B 扫高波段乘数 |
| 傍晚（16–20） | 20m/40m 过渡 | 15m/10m 收尾 | 灰线前 B 先占低波段 |
| 夜间（20–02） | 40m | 80m / 160m | A 守 40m 率；B 抓低波段乘数 |
| 深夜（02–06） | 80m | 160m / 40m | 按实际噪声与率调整 |
| 清晨（06–08） | 40m → 20m | 20m / 15m | 灰线窗口，提前 10–20 分钟到位 |

> **[待验证]** 上表是通用模板；实际要看本台天线、功率、地理、目标（系数 vs 率）。不要把它当规则。

### 2.2 MM 的频段分配

- **固定 ownership [实践]：** 每个波段席“拥有”该波段的一个主频；换频/让频必须经 C 席或指挥确认。
- **不固定 ownership [实践]：** 传播差的波段可以暂时关台，把操作员调到高价值波段；但“关台”不等于“把信号搬到同波段”，因为同波段仍然只能一个信号。
- **MM 的交接单位是“人”，不是“信号” [实践]：** 一个波段可以换操作员，但同一时刻仍只能有一个信号；交接时必须“先停后开”。

### 2.3 交接协议（M2 / MM 通用，可直接执行）

**目标：不产生第三个信号、不出现同波段双信号、不丢频率、不超配额。**

1. **提前 5 分钟预告**：C 席在语音/文字板发“`A 席 20m → 40m，1430Z，B 席接 20m`”。
2. **确认配额**：C 席报“`A 本小时已用 5/8，剩余 3；B 已用 2/8，剩余 6`”。配额不足则取消或改方案。
3. **确认目标频率**：C 席查频率占用表，报“`20m 14250 空闲 / 40m 7150 被 B 占用`”。
4. **先停后开**：
   - 接手方先**只听** 30–60 秒，确认目标频率没有本队其他信号、没有强邻频干扰。
   - 交出手方停止 CQ，发“`A 停 20m`”。
   - 接手方确认后开始 CQ/应答，发“`B 上 20m`”。
5. **记账**：C 席记录“谁、从哪个波段、到哪个波段、时间、是否计入 band change”；A/B 各自的计数器更新。
6. **更新频率表**：释放旧频率、登记新频率；旧频率保留 2 分钟“冷却”标记，防止立刻被对手占掉后本队又回去。
7. **异常回滚**：如果接手方 2 分钟内起不来率，允许回滚；回滚同样计一次 band change，必须重新记账。

> **[规则] 交接不能产生“同波段两个信号”**，哪怕只重叠几秒；MM 同波段多机必须有硬件互锁。M2 两台不同波段是硬约束，交接时也不能出现第三信号。

### 2.4 不撞车的四个机制

| 机制 | 做法 | 适用 |
|---|---|---|
| **单一频率登记表** | 一张表记录 `波段 / 频率 / 席位 / 开始时间 / 状态`；C 席唯一维护 | M2 / MM |
| **先听后发** | 任何新频率，先听 30–60 秒；确认没有本队信号再 CQ | M2 / MM |
| **波段所有权** | 每个波段同一时刻只有一个“主责席位”；跨席使用必须交接 | MM 强制，M2 建议 |
| **硬件互锁** | 同波段多机时，用互锁防止同时发射；没有互锁就不要同波段多机 | 规则要求（CQ WW IX.7） |

## 3. 乘数怎么追

### 3.1 乘数板的字段（C 席维护，所有人只读）

| 字段 | 说明 |
|---|---|
| `mult` | DXCC / CQ zone / WPX prefix（按比赛计法） |
| `band` | 目标波段 |
| `status` | `needed` / `claimed` / `worked` / `expired` |
| `owner` | 认领席位（A/B/某波段席） |
| `spot_time` | 最近一次 spot 时间 |
| `priority` | P0 新高价值 / P1 普通缺口 / P2 低价值 |
| `note` | 频率、呼号、传播备注 |

**规则 [实践]：**

- 一个乘数同一时刻只能有一个 `owner`；认领时写名字，完成后改 `worked`，失败则释放回 `needed`。
- `worked` 只能由日志确认后修改；不能凭“我好像通过了”改状态。
- C 席每 10 分钟把 `needed` 按优先级排序，只向 A/B 播报 **Top 3–5**，不播全量。

### 3.2 谁负责盯缺口

| 组别 | 缺口负责人 | 执行人 |
|---|---|---|
| M2 | C 席（日志/乘数管理）汇总；B 席主抓 | B 席 S&P；A 席在频率上遇到就通 |
| MM | 乘数指挥汇总；各波段席负责本波段缺口 | 各波段席；空闲席可跨波段支援（但不得造成同波段双信号） |
| MS | C 席汇总；MULT 席执行 | MULT 席（CQ WW 不得 CQ） |

### 3.3 缺口怎么传达给 RUN 台

**标准播报格式 [实践]：**

```
[MULT] 缺口 Top3：160m 新增 ZD7（P0，spot 3 分钟前）；80m 新增 VK9（P1）；40m 新增 3C0（P1）。
[MULT] B 席本小时剩余 5 次；A 席剩余 2 次。
[RUN] 收到；A 守 20m，B 去 160m 抓 ZD7，10 分钟内回。
```

**原则：**

1. **只报“可行动”的缺口**：有 spot、有时间窗、有配额、有传播。
2. **报“值不值得动”，不只报“缺什么”**：给出“目标波段、预计停留时间、机会成本”。
3. **RUN 台不被“单个乘数”拉走**：除非是高价值（新 DXCC/新 zone）且配额允许。
4. **播报节流**：同一缺口 10 分钟内不重复播；状态变化才播。

### 3.4 什么时候该停下来让人去扫

**M2 的停跑触发器 [实践 + 待验证]：**

| 触发 | 条件 | 动作 |
|---|---|---|
| 率持续低 | 连续 2 个 10 分钟桶低于本波段阈值 | 评估转 S&P 或换波段 |
| 高价值缺口 | 新 DXCC/zone 在可通波段出现，且剩余配额 ≥1 | B 席去抓；A 席不动 |
| 传播窗口 | 灰线/波段关闭前 20–30 分钟 | 提前下移/上移，不在关闭后硬守 |
| 配额紧张 | 本小时剩余 ≤1 | 只为 P0 缺口使用，停止“找率型”换波段 |
| 操作员疲劳 | 连续高强度 60–90 分钟 | 换人，不换频率（保持信号） |

**MM 的停跑触发器 [实践]：**

- 该波段 eQSO/hr 低于“人力边际产出”阈值，且另一个未开波段预计更高 → 关台/调人。
- 该波段只剩“守株待兔”价值，且乘数指挥有更高优先级任务 → 调人去支援。
- **不要**为了“开更多波段”而违反每波段一个信号；开波段的约束是人和设备，不是规则次数。

### 3.5 乘数重复追的规避

1. **单一乘数板**：只有 C 席/乘数指挥能改 `owner` 和 `worked`。
2. **认领制**：谁认领谁负责；未认领的缺口才能被别人接。
3. **日志优先**：先确认日志已记录，再改 `worked`；不要凭 spot 或口头确认。
4. **跨席播报**：完成一个乘数后，C 席播报“`XX0XX 20m 已通，撤下`”，避免别人再去追。
5. **去重窗口**：同一 `mult+band` 在 10 分钟内只播一次（与 DX-Compass 现有告警去重口径一致）。

## 4. 信息共享怎么不互相干扰

### 4.1 三类数据的流向

| 数据 | 生产者 | 消费者 | 共享方式 | 干扰控制 |
|---|---|---|---|---|
| **Spot 流** | RBN / DX Cluster / 本队 spot | 各席位 | **按席位过滤的队列**，不是全量广播 | 只推“本席相关波段 + 缺口”，同一 spot 去重 |
| **可通性判断** | 传播/分析模块 | 指挥、C 席、各席 | 共享区域×波段矩阵 | 只读，不允许各席各自改口径 |
| **对手位置** | 情报席 | 指挥、C 席 | 共享地图/列表 | 默认不推给所有 RUN 席，避免刷屏 |

### 4.2 Spot 流的分发规则 [实践]

- **A 席（主跑）**：只收“本波段 + 可能影响本频率”的 spot；不收全波段。
- **B 席（猎台）**：收“缺口 + 目标波段”的 spot；按优先级排序。
- **MM 波段席**：只收本波段 spot；跨波段缺口由乘数指挥转派。
- **指挥/C 席**：收全局摘要（每 5 分钟聚合），不收逐条。
- **语音**：同一房间只允许一个“语音主控”播报；其他席位默认仅视觉提示，避免多个 TTS 同时响。

### 4.3 可通性判断的使用边界

- **[实践]** 可通性矩阵是“区域 × 波段”的概率/余量判断，不是“某频点一定能通”。
- **[实践]** RUN 席不应因为矩阵说“可通”就离开高率频率；它只用于“是否值得开这个波段/方向”。
- **[实践]** 矩阵与实测 spot 冲突时，以实测 spot 和当前应答率为准；矩阵只做先验。

### 4.4 对手位置的使用边界

- **[实践]** 对手位置用于判断“哪些波段/方向被占、哪些频率可能被抢”，不用于跟踪对手的每一个 QSO。
- **[实践]** 只给指挥/C 席全量；RUN 席只看“本波段附近的对手”，避免信息过载。

### 4.5 通信纪律（可直接贴墙）

1. **一个决定只说一次**：指挥说完，执行席复述“收到 + 动作 + 时间”。
2. **标准短语**：`上/下 <band>`、`停 <band>`、`占 <freq>`、`放 <freq>`、`缺 <mult> <band>`、`已通 <mult> <band>`、`配额 <used>/<limit>`。
3. **禁止在语音里报长串呼号**：spot 走文字板，语音只报“哪个波段、什么动作”。
4. **交接必须双方确认**：没有“收到”不算交接完成。
5. **冲突优先级**：规则安全 > 日志一致 > 频率占有 > 率 > 乘数。

## 5. 常见事故与规避

| 事故 | 典型根因 | 预防 | 处置 |
|---|---|---|---|
| **两个人同时占一个频率** | 没有频率登记；先发后听；交接无确认 | 单一频率表；先听 30–60 秒；交接双方确认 | 后到者立即停，QSY；记录事故；复盘 |
| **同波段两个信号** | M2 两台误同波段；MM 交接重叠；互锁缺失 | 波段所有权；硬件互锁；交接“先停后开” | 立即停一个；确认不是短暂重叠；检查互锁 |
| **换波段次数超限被判违规** | 配额记在一个人脑里；两台共用计数；跨整点没重置 | 分台计数器；C 席记账；整点重置；剩 1 次时预警 | 立即停止该台换波段；保留证据；必要时联系裁判 |
| **日志不同步** | 各席独立日志；网络中断；重复 ID | 共用一份 N1MM 日志；网络冗余；定期对账 | 以主日志为准；断线席先同步再发射；记录缺口 |
| **乘数重复追** | 没有认领制；完成未播报；spot 重复 | 单一乘数板；认领/完成；10 分钟去重 | 撤回重复任务；以日志为准 |
| **把 M2 当 MS 用** | 误以为 M2 乘数台不得 CQ；误用 10 分钟锁 | 台务卡写清规则族；赛前 10 分钟核对 | 立即纠正；不要因错误规则放弃合法 CQ |
| **把 CQ WW MS 的 10 分钟规则套到 M2** | 规则族混淆 | 规则卡只写当前比赛条款 | 纠正；M2 只看 8 次/小时（ARRL 6 次） |
| **ARRL M2 按 8 次记账** | 用了 CQ WW/WPX 的默认值 | 赛前把配额写成 6；系统 quota 配 6 | 立即按 6 收紧；剩余配额重算 |
| **MM 每波段多信号** | 误以为“MM 无限制” | 每波段一个信号；硬件互锁 | 立即停多余信号；检查互锁 |
| **操作员轮换无记录** | 只换人，不记录 | 轮换表：席位/呼号/开始/结束 | 补记；日志按 operator 字段核对 |

## 6. 可直接执行的操作流程

### 6.1 赛前 T-60 分钟

1. 确定规则族、组别、波段、功率组别，写进台务卡。
2. 分配席位：M2 = A/B + C + D；MM = 6 个波段席 + 乘数指挥 + 日志/指挥 + 传播。
3. 建立三张表：**频率占用表**、**乘数板**、**换波段配额表**。
4. 统一呼号、交换格式、序号规则（WPX M2/MM 每波段独立序号）。
5. 检查硬件互锁（同波段多机时）。
6. 统一通信频道与标准短语。

### 6.2 赛前 T-10 分钟

1. 每个发射席报“席位 / 呼号 / 初始波段 / 初始频率 / 操作员”。
2. C 席核对：两台不同波段、无同波段双信号、配额表归零。
3. 乘数板初始化：按当前波段列出 needed Top 10。
4. 语音主控确认：只由一人播报。

### 6.3 每小时整点（:00–:02）

1. C 席播报：`A 已用 x/8，B 已用 y/8`（ARRL 为 6）。
2. 计数器清零；上一小时未用配额不结转。
3. 乘数板刷新：按新小时传播重排 Top 5。
4. 指挥确认下一小时主攻波段与交接计划。

### 6.4 每次换波段（M2 标准动作）

```
1. 提出：A/B 说“我要从 <band> 去 <band>”。
2. 核配额：C 席报“剩余 n 次”；n=0 则拒绝。
3. 核频率：C 席报目标频率是否空闲；不空闲则换频或等待。
4. 先停：原波段停止 CQ，说“停 <band>”。
5. 后开：新波段先听 30–60 秒，再说“上 <band>”。
6. 记账：C 席记“席位/from/to/时间”，配额 +1。
7. 观察：2 分钟内率起不来，评估回滚（回滚也计 1 次）。
```

### 6.5 每次乘数任务（M2/MM 通用）

```
1. 乘数板出现 needed + spot。
2. C 席/乘数指挥判定：有传播、有配额、有频率、价值足够。
3. 认领：指定 owner；其他人不得重复追。
4. 执行：S&P 或 CQ（按席位角色；M2 允许 CQ，CQ WW MS 的 MULT 不得 CQ）。
5. 完成：日志确认后改 worked；C 席播报“已通，撤下”。
6. 失败：释放回 needed；记录原因（没传播/被抢频/呼号错）。
```

### 6.6 结束前 30 分钟

1. 停止“找率型”换波段；配额只留给 P0 乘数。
2. 核对日志：重复、错呼号、缺 exchange。
3. 核对操作员轮换表与 `operator` 字段。
4. 导出 Cabrillo 前检查：M2 是否标了发射机；WPX 是否每波段独立序号；MM 是否共用呼号。

### 6.7 赛后 30 分钟

1. 导出日志与台账（频率、配额、乘数、轮换）。
2. 复盘三件事：配额是否超、是否出现同波段双信号、乘数是否重复追。
3. 把“实际发生率/实际停留时间”回填到下一场的 [待验证] 参数。

## 7. 规则 vs 实践：一张边界清单

| 说法 | 判定 | 说明 |
|---|---|---|
| “M2 乘数台不得 CQ” | **[实践]**，不是规则 | 只有 CQ WW MS 有这条；M2 没有乘数台规则身份 |
| “M2 也要守 10 分钟” | **错误** | 10 分钟规则只属于 CQ WW MS |
| “M2 两台配额可以互相借” | **错误** | 每台独立；ARRL 明文不可转让 |
| “ARRL M2 也是 8 次” | **错误** | ARRL M2 是 6 次/小时/发射机 |
| “MM 没有 band change 限制，所以可以同波段多信号” | **错误** | 每波段仍只能 1 个信号 |
| “MM 每个波段可以用不同呼号” | **错误** | 一个 entry 一个参赛呼号 |
| “WPX M2 用一个序号就行” | **错误** | 每波段独立序号 |
| “M2 两台必须一台 RUN 一台 MULT” | **[实践]** | 规则只要求两台不同波段、各自记账 |
| “A 席低动、B 席抓乘数” | **[实践]** | 常见分工，不是规则 |
| “同房间只让一个 TTS 播报” | **[实践]** | 避免多席位同时被同一条提醒打扰 |
| “换波段要提前 10–20 分钟到位” | **[实践]/[待验证]** | 取决于本台起跑速度，需实测 |
| “率低于阈值就换波段” | **[实践]/[待验证]** | 阈值需按本台校准 |

---

## 8. 一句话总结

- **M2 的协作核心是“两台不同波段 + 分台配额记账 + 一个共享的乘数/频率台账”。**
- **MM 的协作核心是“每波段一个信号 + 波段席 ownership + 乘数指挥跨波段派活”。**
- **规则只约束信号数、波段、配额、呼号、日志标注；席位名称、谁抓乘数、谁低动，都是实践，必须和规则分开写。**
