# 竞赛三大战术决策：判断依据、量化阈值与可执行规则

- 调研日期：2026-11-11
- 用途：DX-Compass OP 视图的实时提醒规则设计（不涉及界面实现）
- 对象决策：摆摊（Running）、扫地（S&P）、换波段（Band change）
- 额外维度：纬度带 × 季节 × 太阳活动水平，作为规则的条件与阈值修正项，不单独成章讲故事

---

## 0. 阅读约定

### 0.1 证据强度分级

| 级别 | 含义 | 典型来源 |
|---|---|---|
| A | 官方规则原文；或可由计分公式严格推导、不依赖经验的结论 | CQ WW / WPX / ARRL DX / CQ 160 规则页；计分公式 |
| B | 有公开日志、比赛数据或正式发表分析支撑 | K5ZD 公开日志与小时表；K3NA 在 NCJ 对 WRTC2006 日志的量化分析 |
| C | 顶级操作者的公开经验陈述，方向可信但未量化 | K5ZD 比赛笔记；N6TR 演讲引述；N3BB 文章 |
| D | 流传经验法则或本文给出的工程默认值，必须用本地日志校准后才可当阈值用 | “rate 低于多少就撤”一类口号 |

**本文所有数字凡标 D 的，都是“默认值 + 校准位”，不是结论。** 规则清单里每条都标了强度，实施时 D 级阈值必须做成可配置项。

### 0.2 指标定义（实现口径）

以 10 分钟为基本决策窗口，与项目现有墙钟对齐分桶一致（避免窗口滑动导致抖动）。

| 符号 | 定义 | 说明 |
|---|---|---|
| `R_b` | 波段 b 的 10 分钟 QSO 数 × 6 | 原始 QSO 率，**不含乘数信息** |
| `Q_b` / `M_b` | 波段 b 累计 QSO 数 / 累计乘数 | 乘数按赛事口径：CQ WW 按波段计，WPX 全局计 |
| `p̄_b` | 波段 b 累计 QSO 点数 ÷ `Q_b` | 平均每 QSO 分值 |
| `P_sum_b` | 波段 b 累计 QSO 点数 | `Q_b · p̄_b` |
| `V_b` | 一个新乘数的边际价值（等效 QSO 数） | `Q_b / M_b`（推导见 1.2） |
| `t*_b` | 为一个新乘数值得放弃跑台的**最长搜索时间**（分钟） | `60·V_b / R_b − τ` |
| `eQSO/hr` | 等效 QSO 率 | `6 · ΔScore(10min) ÷ (Score / QSOs)`，K3NA 在 NCJ 的 WRTC2006 分析中提出的口径 |
| `τ` | 换频/重新起跑的固定损耗（分钟） | SO1R 默认 2.0；SO2R 0.5；MS 乘数台 0.3（D） |
| `T_rem` | 比赛剩余时间（分钟） | 由赛事配置给出 |

`eQSO/hr` 的意义：把“多打了几个低分 QSO”和“抓到一个新乘数”折算到同一把尺子上。它比原始 rate 表可靠，因为原始 rate 表在“高分台切到低分波段”时会给出反向结论（K3NA 举的 VE3EJ/VE7ZO 例子：20m SSB 66 QSO/hr 换成 40m CW 72 QSO/hr，看着是进步，实际 QSO 点率从 348 掉到 114，point/hr 口径下是退步；但那一轮 40m 抓了 9 个新乘数，eQSO/hr 达 633，最终仍是正确决策）。**结论：只用 QSO 数/hr 判断跑台去留，会在“点值不同 + 乘数不同”的场合系统性判错。**

### 0.3 三条决策的边界

- **Running**：占频、CQ、让台来找你。核心问题是“这个频率/波段/时段还值不值得守”。
- **S&P**：搜索并逐个呼叫。核心问题是“现在扫地的边际收益是否高于守台的边际收益”。
- **Band change**：核心问题不是“传播好不好”，而是“**在规则允许的换波段预算内，把有限次数花在哪个波段上收益最大**”。三者共享同一套价值尺度（eQSO/hr），但约束条件不同：Running 受频率资产（起跑成本、被占风险）约束，S&P 受 spot 流与操作速度约束，Band change 受规则硬约束。

## 1. 决策 A：摆摊（Running）

### 1.1 判断依据：哪些能算，哪些只能看

| 依据 | 可计算性 | 数据来源 | 强度 |
|---|---|---|---|
| 当前波段原始率 `R_b` | 可直接算 | QSO 日志，10 分钟对齐桶 | A |
| 等效率 `eQSO/hr`（含点值与乘数） | 可直接算 | 日志 + 乘数表 + 赛事计分规则 | A（口径）/ B（阈值） |
| 该波段“乘数剩余密度” | 可算（需乘数总表） | DXCC×波段矩阵、WPX 前缀表 | A |
| 频率拥挤度、邻频干扰 | 只能定性/半定量 | 无法从 spot 数据直接得到；可用“连续 CQ 无应答次数”“被迫 QSY 次数”代理 | D |
| 传播窗口剩余时间 | 可估算 | 项目内传播模型（MUF/LUF）+ 灰线 | B（模型）/ C（提前量） |
| 对手同波段活动强度 | 可半定量 | 被监控呼号的 spot 密度、RBN 报告数 | C |
| “这个频率是不是好频率” | 不可量化 | 只能由应答率、pileup 深度间接反映 | D |

**不能量化的部分要承认**：频率质量（是否有邻频大台压制、是否是历史好频点、天线朝向是否匹配该频点上的主要呼入方向）在现有数据里没有可靠代理，规则只能给“起跑/撤离”的时机，不能给“选哪个频点”。

### 1.2 乘数边际价值与“值不值得离开跑台”（严格推导，A 级）

以 CQ WW 为例（乘数按波段计）：

```
Score = Σ_b ( P_sum_b × M_b )
```

- 新增一个波段 b 的乘数：`ΔScore = P_sum_b = Q_b · p̄_b`
- 多打一个平均 QSO：`ΔScore = p̄_b · M_b`
- 两者相除：**一个新乘数 ≈ `Q_b / M_b` 个平均 QSO**

若正在 b 波段跑台、率 `R_b`，离开去搜这个乘数花 `t` 分钟，机会成本为：

```
( R_b / 60 ) · t · p̄_b · M_b
```

令其等于 `P_sum_b`，得**时间预算**：

```
t*_b = 60 · Q_b / ( R_b · M_b )         （分钟，未扣 τ）
```

三个直接推论（都能直接写进规则）：

1. **乘数价值随比赛进程上升**：`Q_b/M_b` 随 QSO 累积变大。开局一小时一个乘数只值几个 QSO，第二天下午可能值十几个。所以“早抓乘数”在经济上并不总是最优，早抓的真正理由是**避免后期窗口关闭后抓不到**（见 1.4）。
2. **同一个乘数，在 QSO 多的波段更值钱**：160m 只有 200 个 QSO 时，新增 160m 乘数只值 `200/M_160` 个 QSO；20m 有 1400 个 QSO 时值 `1400/M_20` 个。**跨波段抓乘数应先补“已经打了很多 QSO 的波段”**，而不是“乘数最少的波段”。这与直觉相反，但由计分公式直接决定。
3. **率越低，越应该去抓乘数**：`t*` 与 `R_b` 成反比。率 100/hr 时 3.6 分钟就回本；率 20/hr 时有 18 分钟预算。**“率低就换波段”这个口号在数学上部分成立，但方向应改成“率低就提高抓乘数的预算”，而不是无脑换波段。**

数值示例（可直接做成 OP 视图的提示文案）：

| `Q_b` | `M_b` | `V_b=Q_b/M_b` | `R_b` | `t*`（τ=2min，SO1R） | 解读 |
|---:|---:|---:|---:|---:|---|
| 400 | 80 | 5.0 | 120 | 0.5 min | 几乎不值得离开，除非乘数就在隔壁 |
| 1500 | 250 | 6.0 | 100 | 1.6 min | 只在“顺手”时抓 |
| 1500 | 250 | 6.0 | 20 | 16 min | 值得专门跑一趟 |
| 3000 | 350 | 8.6 | 60 | 6.6 min | 典型第二天下午的乘数窗口 |

> 前提：乘数按波段计（CQ WW、CQ 160、ARRL DX）。WPX 的乘数是全局的，`ΔScore = P_sum_total`（所有波段点数之和），所以**WPX 里换波段抓前缀的价值显著高于 CQ WW**，同样的 `t*` 公式要把 `Q_b` 换成 `Q_total`。

### 1.3 跑台去留的可量化信号（阈值表）

全部为 D 级默认值，需按本地日志校准；校准方法：取自己过去 3 场同赛事日志，按 10 分钟桶计算，取“该组别该波段该小时段”的 `R` 分布 25 分位作为 `R_stay`，可自动落地。

| 组别 / 模式 | `R_stay` 默认（QSO/hr） | 连续确认 | 说明 |
|---|---:|---|---|
| CW SO HP | 45 | 2 个桶（20 min） | 低于此值且 `eQSO/hr` 不高于 S&P 基准 → 转 S&P |
| CW SO LP | 30 | 2 个桶 | 低功率跑台起量慢，阈值下调 |
| CW QRP | 12 | 2 个桶 | QRP 的跑台价值主要在“被强台发现”，阈值更低 |
| SSB SO HP | 35 | 2 个桶 | SSB 交换长、单信号占带宽宽，绝对率天然低 |
| SSB SO LP | 22 | 2 个桶 | |
| MS / M2 跑台席位 | 60（共享） | 2 个桶 | 多人操作时人工成本低，但受 10 分钟规则约束（见 3.1） |

配套信号（同样 D 级，但比 rate 更“现场”）：

| 信号 | 触发阈值 | 动作 |
|---|---|---|
| 连续 CQ 无应答 | ≥ 5 次（约 45–60 s） | 先判断传播（看该波段 spot 流/信标），不急于换频 |
| 连续 CQ 无应答 | ≥ 8 次（约 1.5 min） | 判定频率已死或波段已落，评估换频/换波段/转 S&P |
| 10 分钟内 dupe 占比 | > 25% | 该频点已被本台“扫干净”，考虑 QSY |
| 被迫 QSY（邻频冲突）次数 | ≥ 3 次 / 10 min | 该频点不可守，优先换频而非换波段 |
| 应答者中本洲/本区占比 | > 80% 且本赛事为 DX 赛 | 跑台“降级”为区域台，考虑换到高波段抢 DX 率 |

> 依据强度：这些信号在 K5ZD、N3BB 等人的操作笔记里反复出现（C），但具体数字没有人公开验证过（D）。**不要把它们写成“科学阈值”，写成“可调默认值”。**

### 1.4 时机：什么时候坚持，什么时候撤

**值得坚持跑台的情形（有前提，不要泛化）**

1. 率高于 `R_stay` 且**该波段 MUF 余量仍在扩大**（传播还在变好）→ 坚持。前提：能拿到 MUF 趋势，而不只是当前值。
2. 率下降但 `eQSO/hr` 未降（掉的是低分 QSO，抓到的是乘数）→ 坚持（K3NA 的 VE3EJ/VE7ZO 40m 案例）。
3. 率下降但**距该波段窗口关闭还有 ≥ 30 min**，且替代波段尚未开 → 坚持，因为换过去也是空的。
4. 多人组别（MS/M2/MM）且跑台席位受 10 分钟规则约束 → 只要没到“必须换”的规则时点，坚持的成本低于违规风险。

**应该撤的情形（同样有前提）**

1. `R_b` 连续 2 桶低于 `R_stay`，且替代波段 `eQSO/hr` 估计 > 当前 1.3 倍 → 撤。前提：替代波段的估计来自**实测**（自己上一轮或对手 spot 流），不是模型空想。
2. 该波段 MUF 余量已 < 0（模型给出该路径已不通），且 spot 流同步衰减 → 撤，不必等 rate 归零。
3. `T_rem` 进入最后 30 分钟且当前波段仍是最优率 → **不撤**，只做频率内优化。末段换波段的期望收益通常低于频率重建成本。
4. 出现极区吸收事件（Kp 跳升、PCA）导致高纬度路径中断 → 撤到低波段/低纬度路径，不要在原波段等“恢复”。

**“整点/半点传播规律”要明确否掉**：传播的周期是**太阳时**（地方时），不是 UTC 整点。UTC 整点处真正发生的事情只有两件：① 多组别的 10 分钟规则/换波段计数在 `:00`–`:59` 窗口重置；② 比赛起止。**把“整点传播好”当规律是 D 级以下的伪规律**，规则引擎不得实现“整点提醒换波段”。反过来，若观察到本台 QSO 率在整点附近跳变，正确解释通常是换班/规则窗口重置/对手批次切换，不是传播。

### 1.5 场景差异（Running）

| 场景 | 结论 | 前提 / 依据 |
|---|---|---|
| SO1R | 跑台是主策略；换波段成本高（`τ`≈2 min），只有 `t*` 明显大于 `τ` 时才离开 | A（公式）+ C（K5ZD 笔记） |
| SO2R | 跑台几乎常开，S&P 由第二电台并行完成；跑台撤离阈值应上调（率低于 30–40/hr 才考虑撤，而不是 45） | C（K2UA 整理的 N6TR 1997 Dayton 演讲：“Two radios—puts the operator back into the equation.”）；B（WRTC2006 数据见 2.5） |
| MS（CQ WW 型 10 分钟规则） | 跑台席位一旦起跑就锁 10 分钟；跑台去留的粒度被规则改成 10 分钟，且**不能靠频繁换波段找率** | A（CQ WW 规则 V.C.1） |
| MS（WPX/ARRL 型小时配额） | 每小时 10 次换波段预算，跑台仍可动，但每次换都要记账；预算应留给乘数，不留给“找率” | A（WPX VI.C.1；ARRL DX 6.1/HCAT.4.2.2） |
| M2 | 两个信号两波段并行，跑台率阈值按“单台”算；每台每小时 8 次（CQ WW/WPX）或 6 次（ARRL DX）换波段配额 | A |
| MM | 每波段一个信号，无换波段限制；“跑台去留”退化为“该波段是否值得继续占人”，判断依据变成该波段 eQSO/hr 与人力成本 | A |
| CW | 单信号带宽窄、交换短，跑台起量快，`R_stay` 高；频率拥挤以百 Hz 计 | C（行业共识） |
| SSB | 单信号 2–3 kHz，拥挤更早出现；跑台起跑慢、被抢频概率高，`τ` 应上调（2.5–3 min） | C/D |
| 国内/区域赛 | 台强、距离短，低功率也能起量；跑台阈值可下调 20–30%，S&P 速度快 | C（N3BB 关于 Sprint 的“两个 QSO 比一个强”论述） |
| DX 赛（CQ WW/WPX/ARRL DX） | 率由“能覆盖多少人口密集区”决定，跑台价值与天线朝向强相关；同一波段不同频点差异巨大 | C（K5ZD：“需要待在他们在的地方”——重心在 EA/Zone 15/16） |
| CQ 160 | 单波段，不存在“换波段”；规则只允许**一个 CQ 跑台频率**，在两个频率间来回属于违规 | A（CQ 160 规则 III） |

## 2. 决策 B：S&P（扫地）

### 2.1 判断依据

| 依据 | 可计算性 | 说明 | 强度 |
|---|---|---|---|
| S&P 实测率（自己上一轮） | 可算 | 上一段 S&P 会话的 eQSO/hr | A（口径） |
| spot 流密度（可用乘数供给量） | 可算 | RBN/cluster 10 分钟该波段新 spot 数、其中“未通乘数”占比 | A（数）/ D（阈值） |
| 乘数缺口结构 | 可算 | 矩阵中“该波段未通且近期有 spot”的 DXCC/前缀数 | A |
| 呼叫成功率 | 可算 | S&P 呼叫数 / 成功数（需日志记录呼叫尝试，多数软件不记） | D |
| 波段拥挤度（跑台被压制程度） | 半定量 | 跑台上“被更强信号盖住”的次数 | D |
| 操作者疲劳 | 不可算 | 只能定性；与 `T_rem`、连续操作时长相关 | — |

**S&P 的核心不是“率”，而是“单位时间拿到多少新乘数”**。所以它的价值尺度应该是 `新增乘数/10min × V_b`，再加 QSO 本身的点值。只盯 QSO/hr 会在乘数已经饱和时高估 S&P。

### 2.2 可量化门槛

1. **转 S&P 的触发条件（三条同时成立，D 级）**
   - `R_b` < `R_stay`（表 1.3）持续 2 桶；
   - 该波段“10 分钟内出现的新 spot 中未通乘数” ≥ 2 个；
   - 估计 S&P 率 > 0.7 × 当前跑台率（估计值取自己上一轮 S&P 的 eQSO/hr；无历史时用默认 20–35/hr）。
2. **S&P 率基准（D 级默认，必须自校准）**

   | 条件 | S&P 默认率（QSO/hr） |
   |---|---:|
   | 无 spot（纯手扫），CW，信号好 | 20–30 |
   | 有 spot 流，CW | 35–55 |
   | 有 spot 流，SSB | 25–40 |
   | 低功率 / 小天线 | 上述值 × 0.6 |

3. **退出 S&P 回到跑台的条件**：连续 2 次“自己 CQ 后有人应答”或 S&P 率连续 2 桶低于 `R_stay` 的 0.7 倍 → 重新起跑。

### 2.3 时机

- **S&P 的优势时段**：① 波段刚开、还没形成稳定跑台时（K5ZD：比赛前两小时全 S&P，因为 40m 还跑不动，此时把 40m 的乘数先扫掉，后面波段好了就不必再回来）；② 跑台被强台压制、频率守不住时；③ 目标波段是“乘数富集但率低”的波段（如 160/80 的 DX 乘数）；④ 末段补漏（`t*` 允许的前提下）。
- **S&P 的劣势时段**：高率跑台期间（机会成本 = 跑台率）；MS 的乘数台**只能** S&P（规则禁止其 CQ），所以 MS 的 S&P 纪律是强制项而非选择项（A 级，CQ WW 规则 V.C.1）。
- **S&P 的隐性成本**：呼叫失败不产生分，且会打断节奏；在 pileup 里“叫 10 次中 1 次”时，实际率要按成功次数算，而不是按听到的台数算。这一点多数 rate 表不体现（D）。

### 2.4 与 Running 的取舍公式

同一 10 分钟窗口内比较两个动作的 eQSO 增量：

```
ΔScore_run  = (R_run/6) · p̄ · M + 新乘数收益
ΔScore_SP   = (N_found · p̄ · M) + (N_newmult · V_b · p̄ · M)
```

判据：`ΔScore_SP > ΔScore_run × (1 + 安全系数)`，安全系数默认 0.2–0.3（D），用于抵消“离开跑台后频率被占”的风险。

## 3. 决策 C：换波段（Band change）

### 3.1 先把规则约束钉死（A 级，逐条核对官方原文）

这是三个决策里唯一有**硬约束**的，规则搞错会导致成绩被判无效或降组，比战术优劣重要得多。

> **注意：CQ WW 的 MS 是“10 分钟规则”，不是“每小时 10 次换波段”；WPX 与 ARRL DX 的 MS 才是“每小时次配额”。** 两者对决策的约束形态完全不同：前者是“时间锁”（每段至少 10 分钟），后者是“次数预算”（可短可长，但总数有限）。把两者混为一谈是常见错误。

**规则带来的战术硬结论**

1. **CQ WW MS**：跑台换波段的粒度是 10 分钟；乘数台也必须在一个波段待满 10 分钟。→ 乘数台不能“扫到一个就换”，必须**按波段成批抓**，这直接改变了 S&P 的路径规划（先扫完一个方向的整段，再整段换）。
2. **WPX / ARRL DX MS**：每小时 10 次预算 ≈ 平均 6 分钟一次。→ 预算必须记账；**绝不能把换波段花在“找率”上**，只能花在“抓乘数”上。K5ZD 在 2006 ARRL DX 的笔记可作为 C 级佐证：“因为每小时 6 次换波段的限制，我们大部分时间只能跑台或 CQ，无法去追 QSO 或乘数”（该场当年 MS 限额为 6 次，现行规则已改为 10 次，结论方向不变）。
3. **M2**：8 次（CQ WW/WPX）或 6 次（ARRL DX）是**每台**的，不能互相借；→ 两台应分工：一台守高率波段少动，一台专职按预算抓乘数。
4. **MM**：无限制 → 决策从“何时换”变成“哪几个波段值得同时开人”，判断依据是该波段 eQSO/hr 与人力边际产出。
5. **CQ 160**：没有换波段，只有“跑台频率”这一个资产；规则禁止双频来回 → 选频后要长期守，撤离成本极高。

### 3.2 传播窗口：换波段该提前还是滞后

**结论：进波段要提前，出波段可滞后。** 但“提前多少”必须是条件化的，不能给单一数字。

- **提前量 Δ_in 的依据**：跑台需要建立频率、形成 pileup，通常要 10–20 分钟才达到该波段的稳定率；因此应在**窗口开启前**到位，而不是看到 spot 才动。
  - SO1R：Δ_in = 20 min（离开原波段的机会成本高，必须一次到位）
  - SO2R：Δ_in = 10 min（第二电台可先监听验证，再决定是否主力切换）
  - MS：Δ_in = 10 min（受 10 分钟规则约束，且乘数台可先过去占位）
  - 以上均为 C/D 级，需按本地日志校准“从起跑到稳定率所需时间”。
- **滞后量 Δ_out 的依据**：模型 MUF 下穿后，电离层余晖仍可维持 20–40 分钟可用传播（尤其 15/10m）。K5ZD 2006 CQ WW 笔记里明确写了“违背常规，在 15m 关闭前就下移”，并说明这是一次有意的提前撤离（C 级）。→ **规则应允许“模型说关了但实测还有 spot/应答”时继续守 15–30 分钟**，而不是到点就切。
- **灰线窗口**：低波段（160/80）的最佳窗口是**路径两端同时接近晨昏线**。窗口长度随纬度剧烈变化（见 4.2）。规则只需判断“两端太阳高度角是否同时落在 [-12°, +3°] 区间”，并给出剩余时间；不需要更复杂的物理模型。
- **短跳/长跳**：短跳（Es，500–2000 km）在夏季白天给 10m（偶尔 6m）带来额外 QSO 来源，与 F2 长跳是**两条独立通道**，可以叠加；长跳（≈180° 大圆）多在灰线附近对特定方向开通。二者都只能定性提示“存在额外机会”，不宜做成硬阈值（C）。
- **整点/半点**：见 1.4，**不存在**传播学意义的整点规律；只有规则窗口在整点重置。

### 3.3 乘数缺口：多大才值得换

用 1.2 的 `t*`，但换波段还要额外付 `τ`（起跑成本）和规则成本（次数/时间锁）：

```
可换  ⇔  (可预期新乘数个数 × V_b) 足够大
         且 预计在该波段停留时间 ≥ 10 min（CQ WW MS）
         且 本小时剩余换波段配额 ≥ 1
```

量化默认（D 级）：

| 条件 | 默认门槛 |
|---|---|
| 目标波段“未通且近 10 分钟有 spot”的乘数数 | ≥ 2（单个乘数不足以支付起跑成本） |
| 目标波段预计 eQSO/hr | > 当前波段 1.3 倍 |
| 预计停留时长 | ≥ 10 min（CQ WW MS 强制）/ ≥ 15 min（其他组别，否则起跑成本摊不平） |
| 剩余换波段配额 | 保留最后 1 次给“本小时出现的高价值乘数” |

**反直觉但重要的一条（B 级）**：新波段的第一批 QSO 乘数占比极高，eQSO/hr 会被“虚高”推到极高水平。K3NA 在 WRTC2006 分析里专门警告：“第一次上某波段，新乘数比例很高，会把 eQSO/hr 推到很高。这通常是正确战术（例如开始填 160m 乘数），但有时只是干扰——为了抓一个刚在空波段出现的普通台，放弃 15m 上好的下午跑台，长期看是亏的。”→ **规则必须对“刚换波段的前 10 分钟”做折扣**（例如前 10 分钟只用 QSO 数与点值计算，不用乘数增益），否则会陷入“不断跳波段、每次都被虚高 eQSO 骗走”的循环。

### 3.4 场景差异（换波段）

| 场景 | 结论 | 前提 |
|---|---|---|
| SO1R | 换波段最贵（`τ`≈2 min + 丢频）；只在 `t*` > 5 min 且目标波段有 ≥2 个乘数时换 | A（公式）+ D（阈值） |
| SO2R | 换波段最便宜（第二电台先听）；但仍受“主力切换”成本约束；可做到“跑台不动、第二台轮询各波段” | C |
| MS（10 分钟型） | 换波段是“计划动作”不是“反应动作”；必须提前排好 10 分钟节拍表 | A（规则） |
| MS（小时配额型） | 换波段是预算动作；每小时 10 次，平均 6 分钟一次，必须记账 | A（规则） |

## 4. 三层条件维度：纬度 × 季节 × 太阳活动

这一节不是独立故事，而是**给上面所有规则加的参数层**。实现方式：先算“环境档位”，再用档位修正阈值与波段优先级。

### 4.1 纬度带：先修正“磁纬”，再谈地理纬

**必须用修正地磁纬度（CGM）而不是地理纬度**判断极区效应：极光带吸收、极盖吸收、跨极路径都由磁纬决定。经验换算（D 级，工程近似）：

```
CGM_lat ≈ 地理纬度 + Δ(经度)
北美内陆 Δ ≈ +3° ~ +5°；欧洲 Δ ≈ −3° ~ 0°；东亚（含中国北方）Δ ≈ 0° ~ +2°
```

实现建议：直接内置 CGM 换算表/公式（IGRF 偶极近似即可），不要用地理纬度硬套。

| 纬度带 | 定义（CGM） | 主要传播特征 | 对三大决策的影响 |
|---|---|---|---|
| 极区 | ≥ 58–60° | 冬季极夜→低波段全天可用但极光吸收风险高；夏季极昼→160/80 基本失效；跨极路径对 Kp 极敏感 | 低波段“窗口”由**黑暗**而非“夜晚”定义；换波段先看 Kp/PCA，再看 MUF |
| 中纬 | 30–58° | 四季分明，灰线窗口 40–70 min，F2 季节变化主导 | 本文所有基准阈值的默认适用区 |
| 低纬/赤道 | < 30° | 赤道异常使日落后 10/15m 延长；80/160 雷电噪声高；跨赤道南北向路径全年可用 | 高波段窗口应**延后**撤离；低波段优先级下调 |

**极区的具体规则含义**

1. **极夜（太阳最大高度角 < 0）**：160/80 不再有 D 层吸收，“白天”也能工作。此时**不要用“夜晚才上低波段”的常规规则**，应按“路径是否在黑暗中 + Kp 是否低”判断。太阳高度角可由经纬度与赤纬直接算：`h_max = 90° − |lat_CGM − δ|`。
2. **极昼（太阳最小高度角 > 0）**：无真正黑暗，160 基本不可用、80 仅短时可用；此时把低波段优先级降到 0–1，资源全部给 20/15/10。`h_min = |lat_CGM + δ| − 90°`。
3. **极光带吸收（Kp 驱动）**：Kp ≥ 5（NOAA G1）时高纬路径开始衰减，Kp ≥ 6–7（G2–G3）时“HF radio propagation can fade at higher latitudes / may be intermittent”。→ 规则：Kp ≥ 5 时，对 CGM > 55° 的路径，**高波段（10/15）优先级 −2，低波段（40/80）相对提升**；不要在原高波段等待恢复。
4. **极盖吸收（PCA，S 级标度驱动）**：S1（≥10 pfu，≥10 MeV）即“对极区 HF 有轻微影响”，S3 为“明显退化”，S4 为“极区 HF 黑障可能持续数天”。→ 规则：S1–S2 时跨极路径降权但不封锁；S3+ 时**直接禁止**把“跨极开通”作为换波段理由；S4+ 视为极区路径不可用。
5. **跨极路径**：只在低 Kp 且高波段有 MUF 支撑时有价值；Kp 高时不要指望“等一等会好”，应改走低纬/长跳。

**低纬的具体规则含义**

1. **赤道异常**：日落后（约当地 19–23 时）在磁纬 ±10–20° 出现 F2 增强，使 10/15m 的窗口比“日落后即关”的直觉晚 1–2 小时。→ 规则：低纬台在日落后 1–2 小时内**不要急于从 15/10 撤离**，先看 spot 与应答。
2. **跨赤道路径**：南北向（跨赤道）路径全年较稳；东西向路径因两端地方时差导致 MUF 不匹配，窗口更窄。→ 规则：同一波段换波段时，优先选“两端地方时接近”的方向。
3. **低波段噪声**：赤道带 80/160 的雷电噪声底显著高（K9LA 对 160m 的噪声测算：居民区 CW 带宽约 S7，乡村 S3）。→ 规则：低纬台 160/80 的跑台 `R_stay` 下调 30–50%，并更早转 S&P（因为听见弱台的能力差，跑台收益低）。

### 4.2 季节：用太阳赤纬 δ 做条件，不写“夏天/冬天”

判断口径（可直接实现）：

```
夏季：|δ| > 15° 且 sign(δ) = sign(lat)
冬季：|δ| > 15° 且 sign(δ) ≠ sign(lat)
春秋分：|δ| ≤ 10°
```

| 季节条件 | 传播事实 | 规则修正 |
|---|---|---|
| 春秋分（\|δ\|≤10°） | 灰线最陡、跨极与长跳窗口最好；40/20 切换最“干净” | 灰线相关规则放宽 10 min；20m 优先级 +1；跨极路径可用性最高 |
| 本地夏季 | 夜短、D 层吸收强；Es 季（北半球 5–8 月，南半球 12–1 月）带来 10m 短跳；低波段 QRN 高 | 160/80 优先级 −1 至 −2；10m +1（Es 通道）；低波段 `R_stay` 下调 |
| 本地冬季 | 夜长、噪声低；低波段窗口长；“冬季异常”使 160 传播优于按日照推算的预期 | 160/80 优先级 +1；`Δ_out` 可延长 15 min；160 规则启用 |
| 极昼/极夜 | 见 4.1 | 覆盖“本地夏季/冬季”的常规判断 |
| Es 季 | 10m（及 6m）出现 500–2000 km 短跳，与 F2 无关 | 只作为“额外机会”提示（C）；不改 F2 阈值 |

### 4.3 太阳活动与空间天气：门控而非背景

| 指标 | 档位定义（建议） | 含义 | 规则作用 |
|---|---|---|---|
| SFI / F10.7 | 低：< 100；中：100–150；高：> 150 | 高中低年高波段可用性 | 波段优先级与 10m 阈值 |
| SSN | 低 < 50；中 50–100；高 > 100 | 与 SFI 同向，可交叉校验 | 同上 |
| Kp | 平静 ≤ 3；活跃 4；风暴 ≥ 5 | 极区/高纬路径 | 门控（4.1） |
| Ap | 与 Kp 同向（日平均） | 补充 | 同上 |
| S1–S5（质子通量） | S1=10 pfu 起 | 极盖吸收 | 门控（4.1） |
| R1–R5（X 射线） | M1 起 | 日照侧短波黑障 | 短时门控：R2+ 时日照侧 10–20m 可能整体消失 10–60 min，**不要在此期间做换波段决策** |

**太阳活动高年不等于全面更好**（必须写进规则，否则会给出错误建议）：

1. 高年 10/15/20 是主力，MUF 抬升使窗口延长，但**160/80 反而变差**：D 层残余电离与大气噪声上升，低波段信噪比下降。→ 高年不要把“低波段乘数”留到后面，应早补。
2. 高年 10m “过开”：多个方向同时开通、信号极强，pileup 深、邻频干扰重，跑台率很高但**单台获取难度上升**；此时不应为“抓一个乘数”放弃 10m 跑台（`t*` 会很小，因为 `R` 很大）。
3. 低年 10m 基本失效：任何“10m 要开了”的模型提示都必须用实测 spot 验证；否则换波段纯亏。低年 40m 成为全天主力，80/160 权重上升。

### 4.4 波段优先级矩阵（D 级先验，必须被实测覆盖）

实现为 `BPI(band) ∈ [0,5]`，初始值如下，再按 4.1–4.3 修正；**实测 `R_b` / eQSO/hr 一旦可用，实测优先，BPI 只用于“没去过的波段”排序**。

## 7. 只能定性、不能做成阈值的东西（必须承认）

1. **频率质量**：好频点、邻频台行为、天线朝向匹配，现有数据无可靠代理。
2. **操作者状态**：疲劳、专注度、CW 抄收能力，直接决定 S&P 真实率，但不可测。
3. **pileup 深度与“能否压住”**：与功率、天线、地理同时相关，无法从 spot 数据反推。
4. **“这个波段感觉要开”**：本质是对 spot 流与噪声的直觉，规则只能用 spot 增速做粗略代理。
5. **对手意图**：可观测其 spot 与波段，但无法判断其是否在蓄意占频或诱导。

对以上各项，规则只能给“观察提示”，不能给“行动建议”；文案必须区分“建议”与“提示”。

## 8. 明确不成立或被夸大的流行说法

| 说法 | 判定 | 理由 |
|---|---|---|
| “整点/半点传播好” | **伪规律** | 传播周期是太阳时；UTC 整点只影响规则窗口与换班。 |
| “rate 低就换波段” | 部分成立，方向要改 | 率低应提高抓乘数预算（`t*` 变大），不等于必须换波段；换波段还受规则与起跑成本约束。 |
| “乘数越少越该去补那个波段” | **错** | 乘数价值是 `Q_b/M_b`，QSO 少的波段乘数反而不值钱（CQ WW 按波段计乘数时）。 |
| “太阳活动高年一定更好” | 不成立 | 高年低波段变差，10m 过开导致 pileup/QRM；且高年低波段乘数应早补。 |
| “S&P 是弱台才做的事” | 不成立 | WRTC 精英台也有 6–15% QSO 来自 S&P；MS 乘数台被规则强制 S&P。 |
| “10 分钟规则就是每小时 10 次换波段” | **错** | CQ WW MS 是时间锁；WPX/ARRL DX MS 才是小时配额。两者不可混用。 |
| “CQ 160 也能靠换波段找乘数” | 错 | 单波段，且规则禁止双频来回。 |
